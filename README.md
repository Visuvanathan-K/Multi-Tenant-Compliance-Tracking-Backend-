# Multi-Tenant-Compliance-Tracking-Backend-
A backend application for managing compliance activities across multiple organizations (tenants).
Built to demonstrate secure REST API development using Java and Spring Boot.

## Planned Features
 - JWT-based authentication and secure password hashing with BCrypt
 - Role-based access control for Admin, Auditor, and User
 - PostgreSQL database with Flyway schema migrations
 - Tenant data isolation
 - Compliance evidence uploads using AWS S3
 - Audit logging
 - Docker support and CI/CD
 - AWS deployment

## Tech
  - **Language**: Java 21
  - **Framework**: Spring Boot 3, Spring Security
  - **Database**: PostgreSQL
  - **Authentication**: JWT, BCrypt
  - **Tools**: Maven, Git, GitHub, Postman
